What’s new in 3.2.0 (Month XX, 2027)#

These are the changes in pandas 3.2.0. See Release notes for a full changelog including other versions of pandas.

Enhancements#

enhancement1#

enhancement2#

Other enhancements#

  • DataFrameGroupBy.rank() and SeriesGroupBy.rank() now accept a numeric_only argument, matching DataFrame.rank() (GH 44438)

  • Display formatting for complex numbers in object dtype and for interval dtype values with float endpoints now respects the display.precision and display.float_format options (GH 25920).

  • The ExtensionArray base tests in pandas.tests.extension.base now issue a errors.PerformanceWarning when the array uses the default, possibly slow, implementation of unique, factorize, argsort, argmin, argmax, or searchsorted (GH 24433)

Other API changes#

  • Index now displays missing float values as NaN rather than nan in its repr, matching Series and DataFrame (GH 64733)

Deprecations#

deprecation1#

deprecation2#

Other deprecations#

  • Deprecated merge() and DataFrame.join() producing duplicated columns when suffixed left and right column labels collide, e.g. suffixes=("_x", "_x"); this will raise a MergeError in a future version (GH 13659)

  • Deprecated pandas.to_pickle, use the DataFrame.to_pickle() or Series.to_pickle() method instead (GH 48402)

  • Deprecated the cache_dates argument in read_csv(), read_table(), and read_fwf() (GH 68705)

Performance improvements#

  • Performance improvement in read_csv() with engine="c" across the board, in tokenizing and in the machinery shared by all column types; large uncompressed local files are additionally read in parallel across multiple CPU cores by default, see above (GH 64347, GH 64515, GH 65350, GH 66271, GH 66272, GH 66273, GH 66274, GH 66276, GH 66798, GH 68314, GH 69632, GH 69748, GH 70140)

  • Performance improvement in PeriodIndex.strftime() with a custom date_format (GH 70106)

Bug fixes#

Categorical#

  • Bug in comparing a Categorical with an iterator raising TypeError instead of treating it as a scalar, as with a tuple (GH 31646)

Datetimelike#

  • Bug in DataFrame.astype(), Series.astype(), Index.astype(), DatetimeIndex, array() and to_datetime() where float dtype data outside the int64 range, such as inf, silently became a valid-looking datetime64/timedelta64 value or NaT; these now raise OutOfBoundsDatetime/OutOfBoundsTimedelta (GH 68926)

  • Bug in DatetimeIndex.strftime(), Series.dt.strftime(), and DataFrame.to_csv() with date_format on Windows silently replacing values that Timestamp.strftime() cannot format (e.g. %y for years before 1900) with their default string representation; these now raise ValueError (GH 58178)

Timedelta#

Timezones#

Numeric#

Conversion#

Strings#

  • Bug in DataFrame.replace() and Series.replace() silently ignoring a compiled re.Pattern for ArrowDtype string and large_string dtypes, including a Categorical of them (GH 69026)

  • Bug in DataFrame.replace() and Series.replace() with regex=True on ArrowDtype string and large_string dtypes raising or silently coercing a replacement the column cannot hold instead of casting to object (GH 70458)

Interval#

  • Bug in IntervalIndex set operations with an empty RangeIndex, and in IntervalIndex construction or astype("interval") from a RangeIndex or non-interval extension array, raising an uninformative TypeError (GH 68343)

  • Bug in concat() and Index.append() with IntervalDtype not retaining an extension dtype subtype, either casting it to a NumPy dtype or raising TypeError (GH 64297)

  • Bug in Series.shift() and DataFrame.shift() with an IntervalDtype column not retaining the subtype, either changing it or raising TypeError (GH 69922)

Indexing#

  • Bug in DataFrame.loc() and DataFrame.iloc() setitem on a 1-column DataFrame with an extension dtype raising when the column key is an all-False boolean mask or an empty list-like (GH 70232)

  • Bug in DataFrame.loc() and Series.loc() setitem with an integer slice raising TypeError where the same .loc getitem succeeds, e.g. on an index of decimal.Decimal values (GH 70219)

  • Bug in Index.difference() dropping elements that are not in other when other was a DatetimeIndex, TimedeltaIndex or PeriodIndex and the elements were strings that parse to its values, or when other was an IntervalIndex and the elements were scalars contained in its intervals (GH 58971)

Missing#

  • Bug in DataFrame.interpolate() and Series.interpolate() with a large limit raising on 32-bit platforms and being very slow on long runs of missing values (GH 34936)

MultiIndex#

I/O#

  • Bug in read_csv(), DataFrame.to_csv() and other I/O functions raising URLError for sftp:// URLs instead of reading or writing them with fsspec (GH 46765)

  • Bug in read_orc() raising whenever filesystem was passed (GH 58746)

  • Bug in read_sas() exhausting memory instead of raising ValueError on a SAS7BDAT file that claims more rows than it can hold, when read from an uncompressed file, a zip archive, or a BytesIO (GH 70721)

  • Bug in read_sas() returning rows that were deleted from an uncompressed SAS7BDAT file (GH 15963)

  • Bug in read_sas() with format="xport" reading zeros as 5.397605e-79 (GH 50670)

  • Bug in DataFrame.to_csv(), DataFrame.to_json(), DataFrame.to_pickle() and similar writers where writing to a file:// URL raised for a new file and silently left an existing file unchanged; writing to other URLs such as http:// now raises instead of silently discarding the data (GH 55828)

  • Bug in DataFrame.to_excel() where a NaN label in MultiIndex columns was written as the last value of that level instead of an empty cell (GH 62340)

  • Bug in DataFrame.to_parquet() with engine="pyarrow" where a misspelled keyword argument truncated an existing file at the destination or was reported as an error about the path (GH 45815)

  • Bug in DataFrame.to_string(), Series.to_string() and DataFrame.to_html() ignoring na_rep for None, pd.NA, and NaT values in object-dtype columns and an explicit na_rep="NaN" for any missing value, and in DataFrame.to_xml() raising for na_rep with nullable, pyarrow-backed, or categorical columns containing missing values (GH 54872)

  • Bug in the repr of a Series or DataFrame with longdouble (e.g. float128) dtype showing values outside the float64 range as 0 or inf (GH 17809)

  • Fixed bug in read_csv() where callable skiprows received incorrect row numbers on 32-bit big-endian architectures (GH 69985)

  • Bug in ExcelWriter with engine="openpyxl" ignoring date_format and datetime_format (GH 44284, GH 59882)

  • Bug in read_sas() raising IndexError or reading the wrong format or label for SAS7BDAT files with columns renamed or relabeled after the file was written (GH 60809)

Period#

  • Bug in Period constructor where the string of a weekly Period such as "2011-12-26/2012-01-01" or "2000-01-03/2000-01-09" was silently parsed as a minute-frequency Period (GH 48000)

  • Bug in Period.strftime() and PeriodIndex.strftime() where %Y was not zero-padded for years before 1000 on Linux (GH 48746)

Plotting#

  • Bug in DataFrame.plot() and Series.plot() with kind="bar" or kind="barh" raising TypeError on timedelta64 data containing NaT (GH 39320)

Groupby/resample/rolling#

  • Bug in Series.resample() and DataFrame.resample() with a PeriodIndex and closed="right" returning shifted labels or incorrect aggregations (GH 44363)

Reshaping#

  • Bug in concat() and the DataFrame constructor losing the freq of a DatetimeIndex or TimedeltaIndex depending on the order of the inputs (GH 64253)

Sparse#

ExtensionArray#

  • Bug in read_csv() and other parsing of strings into a decimal ArrowDtype raising ArrowInvalid instead of parsing the values (GH 69838)

  • Bug in Series.mode() and DataFrame.mode() with dropna=False raising TypeError for "boolean" dtype (GH 70487)

Styler#

  • Bug in Styler methods taking a level argument, such as Styler.hide() and Styler.format_index(), ignoring or raising on negative, out-of-range or NumPy integer levels; level is now resolved as in DataFrame.droplevel(), so an integer matching a level name refers to that level (GH 42933)

  • Bug in Styler.background_gradient() and Styler.text_gradient() coloring missing values with the lowest colormap color instead of the missing-value color when all valid values in a column, row, or table were equal (GH 47695)

  • Bug in Styler.bar() raising TypeError for data containing pd.NA when align is "mean" or a callable, or when cmap is given (GH 56425)

  • Bug in Styler.to_excel() applying styles to the wrong columns when columns selects or reorders columns (GH 42276)

  • Bug in Styler.to_html() where Chrome and other Chromium-based browsers did not apply a style shared by more than 8192 cells to the cells beyond the first 8192 (GH 40913)

Other#

  • Bug in testing.assert_series_equal() and testing.assert_frame_equal() with check_dtype=False and check_exact=True comparing missing values against an object column differently from check_exact=False; pd.NA and NaT no longer match np.nan or None (GH 61473)

  • Bug in util.hash_array() and util.hash_pandas_object() raising UnicodeDecodeError on mixed-type object values containing non-ASCII bytes; bytes in mixed-type values now hash the same as in non-mixed ones (GH 27215)

  • Bug in DataFrame.query() and DataFrame.eval() where == and != against a string gave different results than the same comparison outside of query, e.g. returning no rows for a datetime64, timedelta64, or PeriodDtype column, or raising NotImplementedError with parser="python" (GH 54199)
