Date offsets#

BaseOffset#

BaseOffset

Base class for all pandas date offsets.

Properties#

BaseOffset.freqstr

Return a string representing the frequency.

BaseOffset.kwds

Return a dict of extra parameters for the offset.

BaseOffset.name

(DEPRECATED) Return a string representing the base frequency.

BaseOffset.nanos

Return an integer of the total number of nanoseconds.

BaseOffset.normalize

Return boolean whether the frequency can align with midnight.

BaseOffset.rule_code

Return a string representing the base frequency.

BaseOffset.n

Return the count of the number of periods.

Methods#

BaseOffset.copy()

Return a copy of the frequency.

BaseOffset.is_on_offset(dt)

Return boolean whether a timestamp intersects with this frequency.

BaseOffset.is_month_start(ts)

Return boolean whether a timestamp occurs on the month start.

BaseOffset.is_month_end(ts)

Return boolean whether a timestamp occurs on the month end.

BaseOffset.is_quarter_start(ts)

Return boolean whether a timestamp occurs on the quarter start.

BaseOffset.is_quarter_end(ts)

Return boolean whether a timestamp occurs on the quarter end.

BaseOffset.is_year_start(ts)

Return boolean whether a timestamp occurs on the year start.

BaseOffset.is_year_end(ts)

Return boolean whether a timestamp occurs on the year end.

BaseOffset.rollback(dt)

Roll provided date backward to next offset only if not on offset.

BaseOffset.rollforward(dt)

Roll provided date forward to next offset only if not on offset.
